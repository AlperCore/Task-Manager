# Task Manager 📝

A simple and responsive task management web application built with HTML, CSS, and JavaScript.

## 🚀 About the Project

Task Manager is a web application designed to help users organize and manage their daily tasks through a simple and user-friendly interface.

This project was developed to practice front-end web development and JavaScript programming.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 💻 Getting Started

1. Download or clone this repository.
2. Open the `index.html` file in your web browser.
3. Start using the Task Manager application.
